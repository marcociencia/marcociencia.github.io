# 🧮 Advanced Math Solver - Interactive Mathematical Tool

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://marcociencia.github.io/advanced-math-solver/)

## 🚀 Features

- ✅ **Step-by-Step Solutions** - Detailed breakdowns for arithmetic, algebra, and calculus problems
- 📊 **Interactive Graphs** - Real-time visual representations and plots of mathematical functions
- 📱 **Responsive Design** - Optimized for seamless use across all devices and screen sizes
- 🧮 **Comprehensive Operations** - Column operations with carrying/borrowing, limits, derivatives, integrals, and linear systems
- 🚀 **Fast Deployment** - Live hosting via GitHub Pages

## 🛠️ Tech Stack

- **HTML5 & CSS3**
- **JavaScript (React / Vite)**
- **GitHub Pages**
